3A-1 • PROMPT FIT NOTE

Prompt ไม่ได้มีรูปแบบเดียว

เลือกให้พอดีกับงานก่อน ไม่ต้องเริ่มจากสูตรยาวทุกครั้ง

Prompt สั้น

เหมาะกับงานง่ายและคำสั่งตรง

“สรุปข้อความนี้เป็น 5 ประเด็น”

Prompt แบบธรรมชาติ

อธิบายเหมือนคุยกับเพื่อนร่วมงาน แล้วค่อย Follow-up

“มีลูกบ้านแจ้งปัญหาลิฟต์... ช่วยร่างอีเมลตอบให้สุภาพ”

Prompt Template

บริบท + ข้อมูล + ผลลัพธ์ + ข้อจำกัด/รูปแบบ

3A-2 • RELEARN OS PROMPT TEMPLATE

4 ช่องที่ช่วยให้ AI เข้าใจงานมากขึ้น

นี่คือกรอบเดียวกับที่ใช้ใน Section 3 — เป็น scaffold ไม่ใช่กฎตายตัว

01

บริบท

เราเป็นใคร / งานนี้เกี่ยวกับอะไร / เกิดอะไรขึ้น

02

ข้อมูล

มีข้อมูล ไฟล์ ตัวเลข หรือข้อความอะไรให้ AI ใช้

03

ผลลัพธ์

อยากให้ AI ช่วยทำอะไร และต้องการ Output แบบไหน

04

ข้อจำกัด / รูปแบบ

น้ำเสียง ความยาว สิ่งที่ห้าม รูปแบบตาราง หรือเงื่อนไขสำคัญ

ตัวอย่างจากคลาส: ฉันเป็นผู้จัดการอาคารชุด ดูแลการสื่อสารกับลูกบ้าน → ลูกบ้านแจ้งว่าลิฟต์ขัดข้องหลายครั้ง → ช่วยร่างอีเมลตอบกลับ → ใช้ภาษาสุภาพ กระชับ แสดงความเข้าใจ และไม่รับปากสิ่งที่ยังยืนยันไม่ได้

สรุป

ช่วยสรุปข้อมูลต่อไปนี้เป็น 5 ประเด็นสำคัญ และแยกสิ่งที่ต้องดำเนินการต่อไว้ท้ายสุด

อธิบาย

ช่วยอธิบายเรื่องนี้เป็นภาษาง่าย ๆ สำหรับผู้ที่ไม่มีพื้นฐาน โดยยกตัวอย่างประกอบ 1 ตัวอย่าง

เปรียบเทียบ

ช่วยเปรียบเทียบตัวเลือก A และ B โดยดูจากข้อดี ข้อจำกัด ความเสี่ยง และข้อเสนอแนะ แล้วสรุปเป็นตาราง

จัดเป็นตาราง

ช่วยจัดข้อมูลนี้เป็นตาราง โดยมีหัวข้อ: ประเด็นสำคัญ / ผู้รับผิดชอบ / กำหนดเวลา / สถานะ

วางแผน

ช่วยจัดทำแผนงานจากข้อมูลนี้ โดยแบ่งเป็นเป้าหมาย ขั้นตอน ผู้รับผิดชอบ ระยะเวลา และจุดที่ต้องติดตาม

Research / ถามต่อ

จากข้อมูลนี้ ช่วยระบุสิ่งที่เรารู้ สิ่งที่ยังไม่รู้ และคำถามสำคัญที่ควรถามต่อก่อนตัดสินใจ

HUMAN CHECK

ก่อนใช้ผลลัพธ์จริง — คนต้องตรวจ

ข้อเท็จจริงข้อมูลถูก ครบ และอ้างอิงได้หรือไม่
ข้อมูลส่วนบุคคลมี PDPA หรือข้อมูลลับที่ไม่ควรใส่หรือไม่
โทนภาษาเหมาะกับลูกบ้าน ผู้รับ และองค์กรหรือไม่
การตัดสินใจAI ช่วยร่างได้ แต่คนต้องอนุมัติและรับผิดชอบ
