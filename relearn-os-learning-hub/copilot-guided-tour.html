ก่อนใช้ Copilot ในองค์กร

Work account / Personal account

ตรวจว่ากำลังใช้บัญชีใด เพราะข้อมูลและความสามารถที่เห็นอาจต่างกัน

Microsoft 365 access

Word, Excel, PowerPoint, Outlook และ Teams จะใช้ได้ตาม License และสิทธิ์ขององค์กร

Permissions / Connected experiences

ตรวจสิทธิ์เข้าถึงไฟล์ อีเมล ประชุม และข้อมูลที่เชื่อมกับบัญชีองค์กร

Copilot ใกล้กับ Workflow เดิมของ Microsoft 365

Outlook / Teams

ช่วยสรุปอีเมลหรือการประชุมและดึง Action Items

Word / PowerPoint

ช่วยร่าง ปรับ และต่อยอดเอกสารหรือ Presentation

Excel

ช่วยตั้งคำถาม วิเคราะห์ Pattern และอธิบายข้อมูล

บริบทองค์กร

• ระบุ Owner / Deadline ที่พบในข้อความ
