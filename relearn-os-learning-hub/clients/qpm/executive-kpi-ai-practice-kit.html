01 — เริ่มต้นอย่างไร · How to Use

กิจกรรมต่อยอดจาก Excel / CSV + AI และ PowerPoint Template Setup Guided Demos • เรียนรู้ตั้งแต่ Mapping ข้อมูลจนถึง Dashboard ที่ผ่าน Human QA

STEP 1–2 · PREPARE & MAP

เตรียมไฟล์และจับคู่ข้อมูล

PowerPoint = โครงสร้างเดิม / Excel = ข้อมูลใหม่ • หากตารางใน PowerPoint ครบ อาจใช้เป็น Source Data โดยต้องตรวจสอบก่อน

STEP 3 · HUMAN REVIEW GATE 01

ตรวจ Mapping ก่อนออกแบบ

ตรวจ KPI, Worksheet, Formula, Period, Total และ Missing Data ให้ถูกต้องก่อนอนุมัติ

STEP 6 · PRODUCTION QA / GATE 02

ตรวจผลลัพธ์และอนุมัติ

ตรวจตัวเลข กราฟ Insight และรูปแบบไฟล์ก่อนใช้จริง รวมถึงตรวจว่า PowerPoint และ Chart แก้ไขได้จริงหรือเป็นภาพ

02 — Prompt 01 · Structure & Data Mapping

STEP 1–2 · COPY AFTER UPLOADING POWERPOINT + EXCEL

วิเคราะห์สไลด์และสร้าง Mapping Table

ใช้ Prompt นี้ก่อนเริ่มออกแบบ Dashboard • AI ต้องแสดง Mapping เพื่อให้ตรวจและอนุมัติก่อน

ROLE: Executive KPI Analyst และ Data Mapping QA INPUT: (1) PowerPoint รายงานเดือนเดิม (2) Excel ข้อมูลเดือนใหม่ TASK: วิเคราะห์ทุกสไลด์และจัดทำ Slide-to-Excel Mapping ก่อนสร้างรายงานใหม่ 1. ระบุหมายเลขสไลด์ ชื่อ KPI ตาราง กราฟ และองค์ประกอบที่ต้องอัปเดต 2. จับคู่แต่ละ KPI กับ Worksheet, Column, Field, Formula และ Reporting Period ใน Excel 3. แยก Fixed / Recurring / Conditional Elements 4. ตรวจหน่วย ตัวหาร SUM / Weighted Average และยอดรวมรายทีม 5. ระบุ Missing Data และความขัดแย้ง ห้ามแต่งตัวเลข 6. ถ้าข้อมูลอยู่ใน PowerPoint เท่านั้น ให้ระบุว่าเป็น PowerPoint Source และขอให้ผู้ใช้ยืนยัน OUTPUT: Mapping Table [Slide | KPI | Source Sheet/Field | Formula | Period | Missing Data | QA Status] STOP: แสดง Mapping เพื่อให้ Human Review และรออนุมัติก่อนสร้างหรือแก้ไขสไลด์

03 — Human Review · Mapping Approval

GATE 01 · STOP BEFORE PRODUCTION

ตรวจข้อมูลให้ผ่านก่อนใช้ Prompt 02

  • สไลด์และ KPI จับคู่กับ Worksheet/Field ถูกต้อง
  • สูตร ตัวหาร หน่วย ช่วงเวลา และผลรวมสอดคล้องกัน
  • ระบุ Missing Data / Conflict โดยไม่แต่งข้อมูล
  • แยกหมายเลข Master 24 หัวข้อ ออกจาก Demo 20 หน้า
  • ผู้เรียนยืนยัน Mapping ก่อนดำเนินการ

04 — Prompt 02 · Dashboard Transformation

STEP 4–5 · USE AFTER MAPPING APPROVAL

เปลี่ยนสไลด์เป็น Executive Dashboard

แนบภาพ Dashboard Reference แล้วคัดลอก Prompt 02 ตามด้วย Prompt รายสไลด์ที่เลือก • หากข้อมูลครบใน PowerPoint เดิม ให้ระบุแหล่งข้อมูลและขออนุมัติแทนการสมมุติ Excel

ROLE: Executive KPI Analyst, Dashboard Designer และ PowerPoint Production QA INPUT: (1) PowerPoint ต้นฉบับ (2) Approved Mapping / Verified Source Data (3) ภาพ Dashboard ตัวอย่าง (4) คำสั่งเฉพาะสไลด์ที่เลือก TASK: เปลี่ยนเฉพาะสไลด์ที่ได้รับอนุมัติเป็น Executive KPI Dashboard 1. ยืนยัน Source Data และสูตรจาก Mapping ที่ผ่านการตรวจแล้ว 2. ใช้ภาพอ้างอิงเพื่อ Layout / CI เท่านั้น ห้ามนำตัวเลขจากภาพมาแทน Source Data 3. ออกแบบ KPI Cards, Chart, Key Insights และ Management Actions เท่าที่ข้อมูลรองรับ 4. รักษา QPM CI: ส้ม=ข้อมูลหลัก เทา=เปรียบเทียบ เขียว=ผลดี แดง=ความเสี่ยง เหลืองอำพัน=เฝ้าระวัง 5. เสนอ Layout และรออนุมัติก่อนสร้างไฟล์ 6. หาก AI รองรับ ให้สร้าง PPTX ที่แก้ไขข้อความและกราฟได้; หากไม่รองรับ ให้แจ้งข้อจำกัดจริงและเสนอรูปแบบที่ทำได้ 7. ตรวจยอดรวม สูตร หน่วย ชื่อทีม สี ความชัดเจน และสถานะการแก้ไขได้ของวัตถุ 8. ห้ามแก้ไขสไลด์อื่น ห้ามสมมุติตัวเลข และระบุ DATA REQUIRED เมื่อข้อมูลไม่พอ OUTPUT: Dashboard เฉพาะสไลด์ที่เลือก + Data Sources + QA Checklist + ข้อจำกัดของไฟล์ STOP: รอ Human Approval ก่อนส่งเป็น Final

RULES: ห้ามแก้ไขต้นฉบับ; ห้ามเพิ่มหรือลบสไลด์โดยไม่อนุมัติ; ห้ามคัดลอกตัวเลขที่ฝังอยู่ในรูปเป็น source of truth; ต้องตรวจว่า shape เป็นภาพหรือ editable chart ก่อนแก้; ใช้เลขจาก Excel เท่านั้น; ค่า derived ต้องแสดงสูตรและตัวหาร; ถ้าไม่มี field ให้แสดง [DATA REQUIRED: sheet/column/formula] ไม่แต่งตัวเลข; ทุกหน้าต้องมี DEMO • SIMULATED DATA • OCT 2026. DATA: ใช้ Slide_Map_Validated เพื่อ map หมายเลข Master 1–24 กับ Worksheet; เช็กคอลัมน์จริง ก่อนคำนวณ; Excel ชุดนี้เป็นข้อมูลสมมุต และ sheet ที่เสริมเพื่อ mapping ไม่ใช่ผลจริง. KPI: current/MTD = ต.ค. 2569, YTD = ม.ค.–ต.ค. 2569 เฉพาะข้อมูล flow ที่รวมได้; snapshot ณ สิ้น เดือนห้ามนำมาบวก 10 เดือน; gap = actual−target (pp สำหรับ %); เปรียบเทียบ MoM ด้วยนิยาม เดียวกัน. DESIGN: รักษา QPM logo, black/orange header, white/cream panels, footer, font, geometry. สีส้ม QPM = current/primary, เทา = comparison, เขียว = positive/on target, แดง = risk/off target, amber = warning. ไม่ใช้สีสถานะเพื่อสื่อความหมายผิด. WORKFLOW: (1) อ่านสไลด์ต้นแบบและแสดง mapping + คอลัมน์ + สูตร (2) แจ้งความขัดแย้งของ ข้อมูล/ตัวหาร (3) เสนอ layout ที่คงสไตล์เดิม (4) รออนุมัติ (5) จึงแก้เฉพาะหน้าที่อนุมัติ (6) QA ค่า ตัวเลข หน่วย สี ฟอนต์ overflow และภาพ ก่อนเสนอ Pending Human Approval. OUTPUT PER SLIDE: หมายเลข Demo/Master, ชื่อ KPI, source sheet+columns, MTD/YTD/target gap ตามที่มีข้อมูล, calculation, executive headline, key insight, management action, missing data, QA status. ห้ามประกาศว่า PASS จนตรวจจริง.
