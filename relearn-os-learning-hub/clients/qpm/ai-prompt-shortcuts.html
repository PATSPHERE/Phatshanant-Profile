AI Prompt Shortcuts

คำสั่งย่อสำหรับคิด Prompt ให้เร็วขึ้น ใช้เป็นภาษาคนในการสั่ง AI ได้ทันที

หมายเหตุ: ชุดนี้เป็น RELEARN OS Prompt Shortcuts ไม่ใช่คำสั่ง Slash มาตรฐานของทุกแพลตฟอร์ม
/sum

สรุป

ย่อเนื้อหาให้เหลือสาระสำคัญ

/sum รายงานนี้เป็น 5 bullet
/rewrite

ปรับภาษา

ปรับให้อ่านง่าย สุภาพ หรือเหมาะกับผู้รับ

/rewrite ให้สุภาพและกระชับ
/tone

เปลี่ยนน้ำเสียง

ปรับโทนโดยคงสาระเดิม

/tone professional but friendly
/table

ทำเป็นตาราง

จัดข้อมูลให้เทียบและอ่านง่าย

/table ทำเป็น Finding | Impact | Action
/compare

เปรียบเทียบ

ดูข้อดี ข้อจำกัด และ trade-off

/compare ตัวเลือก A B C
/gap

หา Gap

ดูว่าข้อมูลหรือแผนยังขาดอะไร

/gap ตรวจข้อเสนอฉบับนี้
/risk

หาความเสี่ยง

ระบุความเสี่ยงและจุดควรระวัง

/risk แผนนี้ก่อนนำเสนอ
/action

แตกเป็น Action

แปลงข้อมูลเป็นสิ่งที่ต้องทำต่อ

/action จาก meeting note นี้
/todo

ทำ To-do

สร้างรายการงานพร้อมลำดับ

/todo พร้อม owner และ due date
/plan

วางแผน

แตกเป้าหมายเป็นขั้นตอน

/plan 30 วันสำหรับโครงการนี้
/email

ร่างอีเมล

เขียนอีเมลตามบริบทและผู้รับ

/email แจ้งลูกค้าเรื่องเลื่อนนัด
/meeting

สรุปประชุม

สรุป Decision / Action / Owner

/meeting จาก transcript นี้
/data

วิเคราะห์ข้อมูล

หา pattern, outlier, trend และสิ่งที่ต้องตรวจ

/data วิเคราะห์ CSV นี้
/chart

เลือกกราฟ

เสนอกราฟที่เหมาะกับข้อมูล

/chart ข้อมูลยอดร้องเรียนรายเดือน
/insight

หา Insight

ดึงสิ่งที่ข้อมูลกำลังบอก

/insight จากผลสำรวจนี้
/research

วาง Research

แยกสิ่งที่รู้/ไม่รู้และคำถามต่อ

/research ตลาดนี้ก่อนเข้าพบลูกค้า
/source

ตอบจาก Source

จำกัดให้ใช้เฉพาะเอกสารหรือแหล่งที่กำหนด

/source ใช้เฉพาะไฟล์แนบ
/redteam

ท้าทายคำตอบ

หาสมมติฐาน จุดอ่อน และผลกระทบ

/redteam แผนนี้ก่อนเสนอผู้บริหาร
/check

ตรวจคำตอบ

ตรวจ fact, logic, privacy และสิ่งที่ยังไม่แน่ใจ

/check คำตอบนี้ก่อนส่ง
/simple

อธิบายง่าย

ลดศัพท์เทคนิคและทำให้อ่านง่าย

/simple อธิบายเรื่อง AI Agent
/brief

ทำ Brief

สรุป Context / Goal / Audience / Deliverable

/brief โปรเจกต์นี้ 1 หน้า
/slide

ทำโครงสไลด์

สร้าง storyline และ key message ต่อหน้า

/slide 8 หน้าเรื่องผลการดำเนินงาน
/sop

ร่าง SOP

จัดโครงกระบวนการมาตรฐานจากข้อมูลจริง

/sop จากขั้นตอนการทำงานนี้
/next

หา Next Step

สรุปสิ่งที่ควรทำต่อทันที

/next จากรายงานนี้ 3 ข้อ
