Prompt แบบไหน
เหมาะกับงานแบบไหน?

Prompt ไม่ได้มีรูปแบบเดียว เลือกให้พอดีกับงานก่อน ไม่ต้องเริ่มจากสูตรยาวทุกครั้ง

1

Prompt สั้น

เหมาะกับงานง่ายและคำสั่งตรง

“สรุปข้อความนี้เป็น 5 ประเด็น”
2

Prompt แบบธรรมชาติ

อธิบายเหมือนคุยกับเพื่อนร่วมงาน แล้วค่อย Follow-up

“มีลูกบ้านแจ้งปัญหาลิฟต์ ช่วยร่างอีเมลตอบให้สุภาพ”
3

Prompt Template

เหมาะกับงานหลายเงื่อนไข งานที่ทำซ้ำ หรือเวลานึกไม่ออกว่าต้องบอกอะไร

บริบท + ข้อมูล + ผลลัพธ์ + ข้อจำกัด / รูปแบบ
RELEARN TIP
Prompt ไม่ต้องยาวที่สุด — ต้องให้ข้อมูลพอสำหรับงานนั้น

Prompt Template

โครงช่วยคิด 4 ช่อง ใช้เมื่ออยากให้งานชัดขึ้นและลดการเดาของ AI — เป็น “ราวจับ” ไม่ใช่สูตรตายตัว

01

บริบท

เราเป็นใคร / งานนี้เกี่ยวกับอะไร / เกิดอะไรขึ้น
02

ข้อมูล

มีข้อมูล ไฟล์ ตัวเลข หรือข้อความอะไรให้ AI ใช้
03

ผลลัพธ์

อยากให้ AI ช่วยทำอะไร และต้องการ Output แบบไหน
04

ข้อจำกัด / รูปแบบ

น้ำเสียง ความยาว สิ่งที่ห้าม รูปแบบตาราง หรือเงื่อนไขสำคัญ
ตัวอย่างจากคลาส
ฉันเป็นผู้จัดการอาคารชุด → ลูกบ้านแจ้งลิฟต์ขัดข้องหลายครั้ง → ช่วยร่างอีเมลตอบกลับ → สุภาพ กระชับ แสดงความเข้าใจ และไม่รับปากสิ่งที่ยังยืนยันไม่ได้

Prompt Library

ตัวอย่าง Prompt พื้นฐานสำหรับทบทวนแนวคิด หากต้องการ Prompt สำเร็จรูปแยกตามงาน ให้เปิด Prompt Starter Library

สรุป

ช่วยสรุปข้อมูลต่อไปนี้เป็น 5 ประเด็นสำคัญ และแยกสิ่งที่ต้องดำเนินการต่อไว้ท้ายสุด

อธิบาย

ช่วยอธิบายเรื่องนี้เป็นภาษาง่าย ๆ สำหรับผู้ที่ไม่มีพื้นฐาน โดยยกตัวอย่างประกอบ

เปรียบเทียบ

เปรียบเทียบตัวเลือก A และ B โดยดูจากข้อดี ข้อจำกัด ความเสี่ยง และข้อเสนอแนะ

จัดเป็นตาราง

จัดข้อมูลเป็นตาราง: ประเด็นสำคัญ / ผู้รับผิดชอบ / กำหนดเวลา / สถานะ

วางแผน

จัดทำแผนงานโดยแบ่งเป้าหมาย ขั้นตอน ผู้รับผิดชอบ ระยะเวลา และจุดติดตาม

Research / ถามต่อ

ระบุสิ่งที่รู้ สิ่งที่ยังไม่รู้ และคำถามสำคัญที่ควรถามต่อก่อนตัดสินใจ

Human Check ก่อนใช้ผลลัพธ์จริง

ข้อเท็จจริง • ข้อมูลส่วนบุคคล • โทนภาษา • การตัดสินใจ
