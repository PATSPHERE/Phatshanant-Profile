Universal Prompt Builder — 7 ส่วน

สำหรับงานที่ต้องการ Prompt ละเอียดขึ้น: Role • Goal • Context/Data • Task • Constraints • Output Format • Check ใช้ได้ข้าม ChatGPT, Gemini, Claude และ Copilot

1

Role

อยากให้ AI ช่วยคิดในบทบาทอะไร เช่น ผู้ช่วยสรุปข้อมูล ผู้ช่วยวิเคราะห์ หรือผู้ช่วยเขียน

2

Goal

เป้าหมายปลายทางคืออะไร ต้องการให้ AI ช่วยให้สำเร็จเรื่องไหน

3

Context / Data

ข้อมูลพื้นฐาน เอกสาร ข้อเท็จจริง หรือบริบทที่ AI จำเป็นต้องรู้

4

Task

สิ่งที่ต้องการให้ AI ลงมือทำอย่างชัดเจน เช่น สรุป เปรียบเทียบ จัดลำดับ หรือร่าง

5

Constraints

ข้อจำกัด สิ่งที่ห้าม เวลา งบประมาณ หรือสิ่งที่ห้ามเดา

6

Output Format

กำหนดรูปแบบผลลัพธ์ เช่น ตาราง Bullet 1 หน้า หรือ Action List

7

Check

กำหนดให้ AI ระบุจุดที่ไม่แน่ใจ ข้อมูลที่ขาด หรือสิ่งที่มนุษย์ต้องตรวจต่อ

ประกอบ Prompt ของคุณ

Prompt ที่ประกอบแล้วจะแสดงตรงนี้
RELEARN TIP: ถ้าข้อมูลไม่พอ ให้สั่ง AI ว่า “อย่าเดา ให้ระบุข้อมูลที่ต้องสอบถามเพิ่มเติม”
