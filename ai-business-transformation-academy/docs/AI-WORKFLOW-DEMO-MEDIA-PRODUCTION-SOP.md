# RELEARN OS — AI Workflow Demonstration Media SOP
Status: LOCKED — Approved production approach (2026-11-08)
Scope: Educational reels/videos demonstrating how to perform tasks with AI tools. Applies across tools, not only Claude Cowork.
Owner: RELEARN OS

## Core decision (DO NOT REDESIGN)
Create a **screen-led product demonstration**, NOT a slide-based summary or feature-list presentation.
The audience must SEE the actual workflow: opening the AI product, clicking controls, entering instructions, granting necessary access, seeing the AI process, reviewing outputs, and completing a task.
A static mock slide that merely describes features does not meet this standard.

## Standard production workflow
1. Recover the latest approved script, storyboard, narration/voice settings, CI, and references. Do not invent replacements.
2. Verify the product's current interface and supported actions. Distinguish actual screen capture from a simulated demonstration; do not falsely present simulation as a real recording.
3. Select one concrete, realistic end-to-end user task; map each narration segment to a visible on-screen action.
4. Prepare a complete scene-by-scene storyboard in **two columns**: LEFT = screen visual + precise motion/cursor action; RIGHT = exact Thai voice-over, timing, and synchronization cues. Show EVERY scene for review, not only one sample.
5. Screen should dominate the frame (~80–85% for vertical reels where feasible); include pointer movement, clicks, typing, scrolling, loading/progress, files/folders, and visible output as appropriate. Do not add gratuitous animation or imply unsupported capabilities.
6. Maintain the existing approved RELEARN OS CI, logo, tagline **Prepare • Perform • Transform**, and previously approved voice/avatar settings. Do not guess brand colors or change locked assets.
7. **Approval gate 1:** user reviews the entire storyboard and narration alignment. No full video production before approval.
8. Produce **one representative motion sample** (for Claude Cowork, the client-folder organization scene was chosen) with authentic click-to-result continuity.
9. **Approval gate 2:** check motion, interface accuracy, legibility on mobile, pacing, narration sync, privacy, and quality. Only then scale to all scenes.
10. Final QA of full reel: workflow accuracy, visual continuity, no static slide substitution, text/UI readability, correct CI, voice sync, export format, and deliverables.
